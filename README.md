# Lista de Tarefas

Aplicação de lista de tarefas (to-do list) feita com HTML, CSS e JavaScript puro (sem frameworks), com persistência de dados no navegador.

**Demo ao vivo:** _(em breve — link do GitHub Pages)_

## Funcionalidades

- Adicionar tarefas
- Marcar como concluída (clique no texto)
- Editar uma tarefa (duplo clique)
- Excluir tarefa
- Filtrar por: todas / pendentes / concluídas
- Contador de progresso ("X de Y concluídas")
- Dados salvos no navegador (localStorage) — as tarefas continuam lá se você fechar e abrir de novo

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla JS, sem bibliotecas)
- `localStorage` para persistência de dados no navegador

## Como rodar localmente

Basta abrir o arquivo `index.html` em qualquer navegador. Não precisa de instalação nem servidor.

## O que esse projeto demonstra

- Manipulação do DOM
- Gerenciamento de estado da aplicação (array como fonte única de dados, renderizado na tela)
- Eventos (clique, duplo clique, teclado)
- Persistência de dados no navegador
